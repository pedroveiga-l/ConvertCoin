💱 Conversor de Moedas

Projeto de um conversor de moedas desenvolvido com HTML, CSS e JavaScript, capaz de converter valores de Dólar (USD), Euro (EUR) e Libra (GBP) para Real (BRL), utilizando uma interface moderna e intuitiva.

🚀 Funcionalidades

Converter valores de:

Dólar → Real

Euro → Real

Libra → Real

Interface simples e objetiva

Layout moderno em dark mode

Exibição clara da taxa de câmbio utilizada

Resultado formatado em reais (R$)

🛠️ Tecnologias utilizadas

HTML5

CSS3

JavaScript
